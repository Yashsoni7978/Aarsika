## Fallback Rules

1. **Mobile Fallback:** If a mobile slot (`-mobile`) is missing or unavailable, `ResponsivePhoto` seamlessly falls back to the corresponding desktop asset (`-desktop`).
2. **Placeholder Fallback:** If neither the mobile nor desktop asset is available, `ResponsivePhoto` renders the existing `Photo` flat placeholder with slot metadata. Never displays broken image icons.
3. **Quality & Layout Protection:** Outputs are never cropped or upscaled during optimization. Exact aspect ratios are reserved in the DOM to guarantee zero Cumulative Layout Shift (CLS).
